# 图谱数据清洗报告

- 清洗日期：2026-08-27
- 清洗版本：`2026-08-27-v1`

## 执行边界

原始 Neo4j 数据库未被修改。清洗在由原始 dump 恢复出的独立实例中执行，应用再切换到清洗实例。仓库只保存清洗和验收脚本，不保存 Neo4j store 或 dump。

## 结果摘要

| 指标 | 原始快照 | 清洗服务图谱 | 变化 |
| --- | ---: | ---: | ---: |
| 节点 | 22,328 | 21,712 | -616 |
| 关系 | 145,579 | 120,776 | -24,803 |
| 登记记录 | 16,216 | 16,216 | 0 |
| 规范名重复组 | 600 | 0 | -600 |
| 重复关系组 | 0 | 0 | 0 |
| 无效名称节点 | 5 | 0 | -5 |

616 个节点的减少由 611 个重复实体和 5 个占位实体组成。24,803 条关系的减少包括实体合并时折叠的同义关系，以及与 `Crop "-"`、`Disease "-"` 等占位实体相连的无语义关系。

## 已执行规则

- 统一名称首尾空白、换行和连续空格，2,148 个保留实体的名称发生规范化；
- 合并 `Crop`、`Disease`、`ActiveSubstance`、`PesticideCategory` 中仅大小写或空白不同的实体；
- 有效成分只在规范名一致且 CAS 不冲突时合并；
- 清除导入字段中的空字符串、`-`、`--`、`N/A`、`null`、`*` 等占位值；
- 删除 5 个无效名称实体及其无语义关系；
- 为登记数据增加 `jurisdiction`、`valid_until` 和 `canonical_id`；
- 将 15,953 条登记有效期转换为 ISO `YYYY-MM-DD`，263 条记录没有可用有效期，未出现解析失败值；
- 移除保留实体中的 69,540 个占位字段；
- 从 117 个保留有效成分实体中移除与实体名冲突、未经核验的“中文通用名”翻译；
- 从 234 个有效成分实体中移除乱码俄文字段；
- 对 Chlorantraniliprole 中已确认串入 Chlorpyrifos 的翻译、作用机制和残留说明字段进行隔离；
- 为 8 类实体规范名、有效成分 CAS 和登记标识建立 10 个在线索引。

## 回归结果

- API 已连接清洗实例，`/api/graph/stats` 返回 21,712 个节点、120,776 条关系；
- `Chlorantraniliprole` 可命中中心实体并返回 12 条直接登记关系；
- `4387-901 → Spring barley` 保持 1 跳可达；
- `Prothioconazole → 00A657-62 → Spring barley` 保持 2 跳可达；
- 清洗元数据不会进入用户侧实体属性面板；
- 500 条分层结构回归的实体与路径命中率均为 100%；
- 索引优化后实体检索 P50/P95 为 7.36/50.86 ms，最短路径为 6.60/8.10 ms；
- 后端 Maven 打包通过。

## 仍不能包装成“已解决”的问题

- 16,216 条登记记录仍全部缺少可验证的原始来源 URL；清洗不能补造来源；
- 82 个孤立节点被保留并标记，后续需要回查导入表决定补关系还是删除；
- 92 个超长名称疑似由多个作物或病虫害拼接而成，自动拆分可能改变语义，当前只标记待复核；
- 评测抽样又发现 100 条包含三次以上重复词或 `hygiene` 异常词的高风险名称；该结果与超长名称有重叠，已加入审计查询但未自动改写；
- 数据中的同义词、翻译和复合名称尚未经过农业领域词表或人工金标准校验；
- 精确名称和 CAS 已改为索引命中；别名、拼写容错和中文名称仍依赖模糊回退，后续需要全文索引或专用检索层。
